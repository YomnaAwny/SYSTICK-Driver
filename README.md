
# SYSTICK-Driver

This repository contains a Systick driver for STM32, developed as part of the IEEE Alexandria University Student Branch, Embedded System Team.

## Technologies Used
- Microcontroller: STM32
- Development Environment: Eclipse
- Programming Language: C

## Functionality
The Systick driver provides a system timer that generates periodic interrupts, enabling precise timing and scheduling in embedded applications. This driver allows for configuring the Systick timer's frequency, enabling/disabling interrupts, and handling timer events.
